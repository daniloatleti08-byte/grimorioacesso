# Grimório - acesso via GitHub + Vercel

Projeto estático pronto para subir no GitHub e importar no Vercel.

## Arquivos
- `index.html` - página de acesso com visualizador embutido
- `grimorio.pdf` - PDF do produto
- `assets/capa-grimorio.webp` - prévia da capa
- `vercel.json` - configuração do Vercel

## URLs depois do deploy
Se seu domínio for `https://exemplo.vercel.app`:

- Página de acesso: `https://exemplo.vercel.app/`
- URL bonita alternativa: `https://exemplo.vercel.app/acessar-grimorio`
- PDF direto no navegador: `https://exemplo.vercel.app/grimorio.pdf`

Para entrega após a compra, prefira a URL `/acessar-grimorio`.

## Publicação
1. Crie um repositório no GitHub.
2. Envie todos os arquivos e a pasta `assets` mantendo a estrutura.
3. No Vercel, escolha **Add New > Project** e importe o repositório.
4. Não é necessário framework ou comando de build.
5. Clique em Deploy.

Observação: qualquer pessoa que tiver o link poderá abrir o PDF. Para controle individual de acesso, use a área de membros da plataforma de pagamento.
